# michael-gee.dev

Personal site for Michael Gee - software engineer.

Static, single-file (`index.html`), no build step or dependencies. Hosted on GitHub Pages at [michael-gee.dev](https://michael-gee.dev).

## Local preview

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```

## Deploy

Pushing to `main` publishes automatically via GitHub Pages. The custom domain is set in `CNAME`.
